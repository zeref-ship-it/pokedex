# Pokédex App - Project Instructions

## Overview
A React Native Expo Pokédex mobile app that fetches data from PokeAPI and stores favorites in Firebase Firestore. All UI text in Brazilian Portuguese. Dark theme, Pokemon-themed design.

## Tech Stack
- React Native + Expo (SDK 54), TypeScript, expo-router
- Firebase JS SDK v9+ (modular) for Firestore CRUD
- react-native-reanimated for animations
- expo-linear-gradient for gradients
- @expo/vector-icons (Ionicons, MaterialCommunityIcons)

## Design
- **Theme**: Dark mode with Pokemon Red (#DC2626) primary, Gold (#FACC15) accent
- **Colors**: bg=#0F0F0F, surface=#1A1A1A, elevated=#242424, text=#F5F5F5, secondary=#A3A3A3
- **Fonts**: Poppins (Regular, SemiBold, Bold) with system fallbacks
- **Type badges**: Colored pills matching Pokemon type colors

## Navigation Structure
```
app/
  _layout.tsx       → Root Stack (fonts, FavoritesProvider, ErrorBoundary)
  index.tsx         → Redirects to /tabs
  +not-found.tsx    → 404 handler
  tabs/
    _layout.tsx     → Bottom Tab Navigator (Pokédex, Favoritos)
    index.tsx       → Home: Pokemon grid with search, pagination, favorite toggle
    favorites.tsx   → Favorites list from Firestore
  pokemon/[id]/
    index.tsx       → Pokemon detail with stats, abilities, favorite actions
  favorite/[id]/
    edit.tsx        → Edit nickname/notes for a favorite
```

## Firebase
- Collection: "favorites"
- Schema: { pokemonId, name, imageUrl, types[], nickname?, notes?, createdAt }
- Real-time with onSnapshot
- Config via EXPO_PUBLIC_FIREBASE_* env vars

## Key Components
- PokemonCard, FavoriteCard, TypeBadge, StatBar, SearchBar
- LoadingSpinner (rotating pokeball), ErrorState, EmptyState, ErrorBoundary
